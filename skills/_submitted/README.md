## 타임리 대화에서 나온 개선 (원고에 없던 것)

대화 과정에서 타임리가 제안해 채택한 것들:

| 항목 | 내용 |
|---|---|
| **요소별 최소 신호** | "3개 중 2개 들어오면 확보" — 확보 판정을 느낌에서 확인 가능한 조각으로 내림 |
| **꼬리질문 던지는 입 5종** | 구체화 / 대비 / 이유 / 수치·범위 / 결과·이후 |
| **유도 금지** | 감정 추정("힘들었겠어요?"), 끼워 맞추기 금지 |
| **자가 검증 위치 분리** | 초안 직후만이 아니라 캐는 중간에도 경량 정렬 점검 |
| **예외 처리 3단 원칙** | 짚어주기 → 가능한 만큼 정리 → **선택지 주기** |
| **톤 원칙 "대안에 선 박기"** | 좁은 문을 열 때도 "새로 만들지 않는다"가 보이게 |
| **시연 정직성 조건** | 막힘 하나 포함 / 미확보 하나 남김 / 답안 문장의 출처 표식 |
| **재료 점검을 게이트로** | 있음·없음·각도 안 맞음을 갈라 캐기 여부를 결정 |
| **전환이 약한 문항 처리** | 억지로 실패-재시도를 만들지 않고 기준 이동으로 대체, 그래도 없으면 비워둠 |

## 원고에서 유지된 것

- 검증 축 4개 (판단 / 회복 / 관계 / 지속) + 문항 형태 3개
- 축 단위 캐기 (문항 단위가 아니라) — 10~15분 유지의 근거
- 네 박자 구조 (주장 / 장면 / **전환** / 잔상)
- 분량은 문장 수로 (목표 글자수 ÷ 65)
- 재사용 2회 한도
- 소재 카드 / 인계 카드와 이어쓰기
- 시연 모드
